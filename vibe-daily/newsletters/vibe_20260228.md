## 💡 AI 编程技巧 Today

**Tip 1: 善用 Claude Code 的新 `/batch` 命令**
最新版 Claude Code 的 `/batch` 命令非常适合对多个文件执行相同或类似的操作（如重命名变量、统一格式化、添加注释头）。在操作前，先用自然语言描述清楚批量处理的规则，AI 会生成更准确、一致的变更脚本，比逐个文件处理效率高得多。

**Tip 2: 为 Copilot Chat 明确“对话边界”**
在使用 Copilot Chat 进行长对话时，定期使用“让我们重新开始”或“总结以上讨论”之类的指令来重置或锚定上下文。这可以防止对话历史过长导致的焦点漂移，确保 AI 始终基于最新、最相关的指令生成代码和建议。
